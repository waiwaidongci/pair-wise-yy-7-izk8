# 古船模型帆索分段张紧

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 代码分三处

| 文件 | 职责 |
| --- | --- |
| `lib/tasks.js` | 任务/规则：分段张紧层级、张紧器领用锁定、读数偏离判定、换人复核、参数变更失效 |
| `lib/records.js` | 记录：JSON 文件存取、模型/任务/审计日志结构、统计 |
| `lib/pages.js` | 页面：HTML 与前端交互（规则一律以服务端返回为准） |
| `server.js` | HTTP 路由薄层 |

## 作业规则

1. 每根帆索登记**目标张力**（满张力读数）和所用**张紧器**。
2. 分段读数：**三成（30%）→ 六成（60%）→ 满张力（100%）**；每根索每层都记完，才允许进入下一层，已越过/已复核的层锁定。
3. 张紧器**领给某模型后，整套张紧（三层全部）结束前不能给别的模型**；整套结束自动归还。
4. 任一层读数偏离该层目标 **超过 5%** 立即停用，模型进入“待复核”，全套张紧停住；必须**换另一名师傅**（不能是记录师傅本人）复核：放行后继续，或驳回后重记该层。
5. **桅杆数量或帆索材料修改**后，已有张紧读数全部失效，帆索需重新登记（张紧器仍留在本模型）。
