# 古船模型帆索分段张紧

运行：

```bash
npm start
```

访问 `http://localhost:3038`。

## 张紧规矩

- 每根帆索先**登记目标张力和张紧器**，再按 **三成 → 六成 → 满张力** 三层记录读数（系统按目标张力自动给出每层目标值）。
- **整套分层**：同模型所有索把某层都记完，才能进入下一层；单层内不能跳层。
- 读数偏离本层目标 **±5%（严格大于 5%）** 立即停机，该索锁定；必须换**另一名师傅**（读数人不能自复核）复核放行后，重记本层。
- 张紧器领给一个模型后，整套张紧结束（三层全齐，模型转「待复核」）前不能发给别的模型；完成后自动归还。
- **桅杆数量或帆索材料变更**：旧张紧结果立即作废（读数归档进台账、任务退回三成重拉、作废次数累计），张紧器仍由本模型占用。

## 三处分开

| 位置 | 文件 | 职责 |
| --- | --- | --- |
| 任务（业务规则） | `tensionTasks.js` | 分层门控、±5% 判定、停机/复核、领用互斥、变更失效；纯函数 |
| 记录（台账） | `tensionRecords.js` + `data/tension-ledger.json` | 事件只追加不涂改；张紧器领用状态由事件推导 |
| 页面（界面） | `tensionPage.js` | 登记、记读数、复核、变更四个操作区 + 进度卡 + 台账 |
| 路由 | `server.js` | HTTP 薄壳，把三处串起来 |

模型档案仍存 `data/model-rigging-calibration.json`，张紧事件存 `data/tension-ledger.json`。

## 测试

```bash
npm test
```

端到端脚本会在临时数据上跑完整流程（领用互斥、分层门控、偏差停机、换人复核、整套归还、变更失效）。
